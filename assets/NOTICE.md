# Asset sources

`banner-dark.svg` and `banner-light.svg` are original vector artwork created for Nguyen Van Anh Tuan's GitHub profile. They use system fonts and contain no external resources or scripts.

`skills-dark.svg` and `skills-light.svg` were downloaded on 2026-11-12 from [Skill Icons](https://github.com/tandpfun/skill-icons), by tandpfun, under the MIT license. The upstream copyright and license are preserved in [licenses/skill-icons-MIT.txt](licenses/skill-icons-MIT.txt). Product names and logos belong to their respective owners.

Source URLs:

```text
https://skillicons.dev/icons?i=aws,kubernetes,docker,terraform,ansible,jenkins,githubactions,gitlab,prometheus,grafana,python,bash&perline=12&theme=dark
https://skillicons.dev/icons?i=aws,kubernetes,docker,terraform,ansible,jenkins,githubactions,gitlab,prometheus,grafana,python,bash&perline=12&theme=light
https://raw.githubusercontent.com/tandpfun/skill-icons/main/LICENSE
```

Both icon strips are stored locally so the profile does not require the icon service at display time.

`metrics-dark.svg` and `metrics-light.svg` are generated from real GitHub account data with [lowlighter/metrics](https://github.com/lowlighter/metrics), under the MIT license preserved in `licenses/metrics-MIT.txt`. The workflow configuration is in `.github/workflows/metrics.yml`.
